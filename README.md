# 帳本 — 個人記帳 PWA

免費、離線可用的個人記帳本。**資料只存在你自己的裝置裡**（瀏覽器本機儲存），沒有伺服器、免註冊、無廣告、不收集任何資料。

## 功能

- 📒 快速記帳：金額鍵盤＋34 個家庭開支分類（可自訂名稱、emoji、上傳／貼上圖片）
- 📊 月比／季比：與上月、上季、去年同期的偏差比較（偏差尺、預算對照柱）
- 🧮 結算表：每類「預算 / 實際 / 偏差」一目了然
- 🤖 AI 分析：本機統計拆解，直接講出變化來自「次數」或「單次金額」（免費、不上雲端）
- 💰 預算進度環、近 14 日趨勢圖（含量度尺與每日分界）
- 🔒 可選 4 位數密碼鎖（本機防護）
- 🌐 中文 / English 介面切換
- 📱 PWA：可安裝到主畫面、離線使用

## 備份與換機

設定 → 資料 → **匯出備份（JSON）** 下載到本機（可自行存進 Google Drive／iCloud），
新裝置用 **匯入備份** 還原 — 記錄、自訂分類、圖片、預算、密碼都會完整帶走。

## 技術

純靜態網站（HTML / CSS / JavaScript），無後端、無建置流程。任何靜態託管皆可部署。
